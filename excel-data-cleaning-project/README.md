# Excel Data Cleaning Project

## Project Overview
This project focuses on cleaning and preparing a retail sales dataset for analysis using Microsoft Excel.

## Dataset
The dataset contains sales records including order dates, ship dates, sales, and customer information.

## Data Cleaning Steps
- Checked for duplicate records
- Handled missing values(0)
- Standardized column names
- Formatted data types (dates, numbers)
- Created new columns (month, year(order dates))

## Tools Used
- Microsoft Excel

## Outcome
The dataset was cleaned and structured, making it ready for further analysis and visualization.
